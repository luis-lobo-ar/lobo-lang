# Compact reading packet pilot

This additive packet targets four language areas where earlier tests exposed missing or unclear facts.
Lobo remains Core 1.11/compiler 1.11.2. The older tested reference and graph remain unchanged.

The [cards](cards.json) contain buffer signatures, units and runtime conditions; nominal constructor and
inference rules; contextual try; and contract typing/purity rules. Sources have hashes and anchors.
Provenance stays in this artifact. Agent prompts receive the version header and relevant card text.

The reading-only guide preserves the old semantic paragraphs while removing editing/check advice and
adding a reading-mode cue. It is generated by [the pilot driver](../../../benchmarks/matched-study/compact.py).
Each card is short enough that guide plus card remains smaller in bytes than the original guide.
Reported tokens and quality must still be measured.

Coverage is checked for this pilot. It is not a complete language reference. Fourteen buffer signatures
receive positive/negative static compiler probes. New runtime and admission examples receive native,
evaluator and static checks before model calls. Cards contain general rules rather than scored answers.

Decision [0068](../../../decisions/0068-small-guide-and-fact-pilot.md) bounds the test to 24 attempts.
The three arms isolate guide cleanup and the conditional addition of targeted facts. This is a small
development test, with no blind holdout or general improvement claim.
